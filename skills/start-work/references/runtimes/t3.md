# T3 Code runtime

Read this adapter before dispatching a worker through T3 Code. Shared briefs and
resource ownership follow [Orchestration](../orchestration.md).


Use native subagents for a child on the current provider, on a model it offers,
with no settings beyond the parent. Use `delegate_task` for another provider's
model, user-requested settings, a requested separate checkout, an explicit
`delegate_task` request, or a background agent. Top-level thread creation is
reserved for a user request for a new thread.

Before the first `delegate_task` in a thread, call `orchestrator_capabilities`.
Use its actual provider/model IDs and put settings in `target.options`. Repeat
discovery only after an error or a user-named provider change. Inherit permission
mode unless the user requests a supervised child; a permission mode is not a
read-only role. Set review limits in the brief.

Use the default shared isolation for the existing checkout. When the user
requests a separate checkout, use `isolation: "worktree"`; T3 prepares it from
the parent commit without uncommitted changes. Account for required dirty changes
before dispatch. Let T3 prepare the checkout rather than creating it in the shell
or the task prompt. Read the live tool schema for supported arguments.

Keep the returned `taskId` and thread `link`. Follow a running delegate's `next`.
If it says completion will wake the parent, end the turn and resume on that event.
Use neither polling nor a separate wait for that run. Cancel replaced, unneeded, or
user-cancelled delegates with `task_cancel` and their `taskId`.

If a requested provider or model is unavailable, report that limit and complete
independent permitted work. Keep the user's selection until they change it.
Use neither another provider nor a CLI as a silent substitute.

For reviews routed through `delegate_task`, start a new task for each review or
re-check with its own brief, findings to verify, and objections to resolve. Use
fresh independent evidence for the initial review. A thread message is not a
reviewer dispatch.
